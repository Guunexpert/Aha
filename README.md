# How to run (Windows) 
from source

```bash
git clone https://
cd AhaSR
zig build run-program
```
build the executable so you can run/share it without need dependency
```bash
zig build -Doptimize=ReleaseSafe
```
the compiled exe in...
```bash
zig-out\bin\(the exe)
```
# Setup the Launcher.exe
copy launcher.exe and hkprg.dll from launcher folder inside AhaSR and paste them inside your client folder. Then open your launcher.exe with administrator.
